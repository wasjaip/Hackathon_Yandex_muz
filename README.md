# Хакатон Яндекс Музыки — поиск каверов

Командный ML-проект для поиска, группировки и ранжирования каверов музыкальных треков.

## Бизнес-задача

Каверы могут ухудшать или, наоборот, обогащать персональные рекомендации. Цель проекта — научиться определять, является ли трек кавером, связывать его с оригиналом и группировать связанные композиции.

## Что решали

- классификация `кавер / не кавер`;
- поиск похожих треков;
- группировка каверов с исходным произведением;
- ранжирование треков внутри группы по схожести и метаданным;
- эксперименты с NLP-представлениями текстов.

## Стек

`Python` · `pandas` · `scikit-learn` · `CatBoost` · `XGBoost` · `LightGBM` · `NLP` · `embeddings`

## Данные

В работе использовались:

- разметка каверов;
- метаинформация о треках;
- тексты песен.
